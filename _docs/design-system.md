# Design System

**Status: in progress**

This document specifies the visual and interaction design for ytdigest. It is currently a placeholder while the design language is being formalized.

## Sections

- **Color palette** — primary, accent, semantic colors and their CSS variable names
- **Typography** — font families, scales, line heights, and weight hierarchy  
- **Components** — buttons, inputs, modals, cards, and their variants
- **Patterns** — layout, spacing, and interaction patterns used across the app
- **Accessibility** — contrast ratios, keyboard navigation, screen reader support

See `web/` for the current implementation. Updates to this document should be reflected in the code, and vice versa.
